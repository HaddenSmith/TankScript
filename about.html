About TankScript

What is TankScript?

TankScript is a programming game about designing an algorithm that controls a tank. Players do not manually drive their tanks during a match. Instead, their JavaScript behavior makes decisions for them.

Each tank can move, rotate, aim, and shoot in an automatic 2D arena against a tank created by another user.

How to play

  1. Create an account and name your tank.
  2. Write JavaScript behavior using the available tank commands.
  3. Save your tank and select it for a battle.
  4. Choose an opponent and start the match.
  5. Review the battle, then improve your code for the next match.

Basic rules

  • Battles run automatically after both tanks are selected.
  • A tank's programmed decisions determine its movement and attacks.
  • A battle ends when one tank is defeated or the match reaches its time limit.
  • Wins and losses will eventually be recorded for each tank.
