Program a tank. Battle the competition.

TankScript is a competitive programming game where you write JavaScript that controls a tank in an automatic 2D battle arena.

Your code decides when your tank moves, rotates, aims, and shoots. Then watch it compete against tanks created by other players.

Start coding and create a tank

Build your battle strategy

Create a tank, write its behavior, and improve your algorithm after every battle. Wins and losses will eventually contribute to tank statistics and a shared leaderboard.
